# Telegram-бот «Get Rich»

Бот @deysscoutbot. Токен и chat id лежат в `secrets/telegram.env`, их нельзя никуда коммитить и печатать.

## Что приходит утром

1. **Дайджест:** почта, продуктовый топ-10, Solutions топ-5, напоминания о неоткликнутых, задачи (визы, SA-тренировка), статистика по трекам, фоллоу-апы, ссылка на трекер.
2. **Карточки вакансий:** подпись (компания, роль, локация, оценка, зарплата, почему подходит) + альбом из CV и письма.
3. **Кнопки стран:** «Куда дипдайвим? 👇» с числом вакансий по странам и «➕ Ещё 10».
4. Отдельными сообщениями: консалтинг-лиды, LinkedIn-контакты (понедельник), визовые дела.

## Кнопки

| Кнопка | Что делает | Когда результат |
|---|---|---|
| ✍️ Письмо | Ставит в очередь письмо под вакансию | В утреннем прогоне. Срочно — написать Claude «сделай письма» |
| 💶 Зарплата | Показывает вилку или оценку, на чём основана и что писать в анкете | Сразу, если оценка уже есть в `jobs_meta.json`, иначе утром |
| ✅ Откликнулась | Меняет кнопку на «✅ Откликнулась ДД.ММ», ставит отметку в очередь | Утром трекер переводит вакансию в «Откликнулась» (только из статуса «new») |
| 🇳🇱 🇬🇧 … страны | Присылает очередь вакансий по стране | Сразу |
| ➕ Ещё 10 | Следующие 10 лучших по всем странам | Сразу |

## Своя вакансия

Пришли боту ссылку на вакансию, команду `/vac <ссылка или текст>` или просто вставь текст вакансии (от 200 символов). Бот ответит «📥 Вакансию приняла» и поставит её в очередь `data/ondemand.jsonl`. Ближайший прогон Claude разберёт её как найденные: оценка, «почему», зарплата, CV и письмо, запись в трекер и задача «Откликнуться» в плане дня. Результат придёт карточкой «📥 Твоя вакансия» с кнопками ✍️ 💶 ✅.

LinkedIn Claude не открывает: для вакансий оттуда пришли ещё и текст одним сообщением.

## Скрипты

| Скрипт | Назначение |
|---|---|
| `send_tg.sh <file> [more\|kb]` | Отправить HTML-сообщение; `more` добавляет кнопку «Ещё 10», `kb` — клавиатуру стран из `data/keyboard.json` |
| `send_job_docs.sh <caption> <cv.pdf> [cover.pdf] [doc id]` | Карточка вакансии. С doc id появляются кнопки ✍️ 💶 ✅ |
| `make_cover_pdf.sh <txt> <out.pdf> "Company — Role" [заголовок]` | Письмо в PDF в стиле CV |
| `make_keyboard.sh` | Клавиатура стран из `data/country_queue.json` |
| `send_country.sh <BUCKET>`, `send_more.sh` | Очереди по стране и «Ещё 10» |
| `watch_check.sh` | Почасовая проверка `watchlist.tsv` |
| `tg_listener.sh` | Фоновый long-poll: кнопки, команды, почасовой watch |

## Слушатель (LaunchAgent)

Работает в фоне и перезапускается при входе в систему.

```bash
# установить или переустановить
"/Users/katedeys/job scout/scout/install_listener.sh"
# перезапустить после правки tg_listener.sh
launchctl kickstart -k gui/$(id -u)/com.katedeys.getrich
# проверить, что жив
launchctl list | grep getrich
# лог
tail -50 "/Users/katedeys/job scout/scout/data/listener.log"
# удалить
launchctl bootout gui/$(id -u)/com.katedeys.getrich; rm ~/Library/LaunchAgents/com.katedeys.getrich.plist
```

## Если кнопки не отвечают

1. `launchctl list | grep getrich`: в первой колонке должен быть номер процесса.
2. Посмотри `data/listener.log`.
3. Перезапусти командой `kickstart` выше.
4. Ноутбук должен быть включён и онлайн: слушатель работает только на этом компьютере.
