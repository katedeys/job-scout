# Ежедневный прогон

Запланированная задача `job-scout-daily` в приложении Claude запускается каждый день в 9:05 по Астане.
Её промпт просто отправляет Claude к `scout/DAILY.md`, а все правила лежат там. Чтобы поменять поведение
бота, правь `DAILY.md`, а не задачу.

## Шаги

| Шаг | Что происходит |
|---|---|
| 0 · Почта | Claude читает Gmail за 2 дня, только чтение: отказы, приглашения, подтверждения откликов. Статусы обновляются в трекере |
| 0b · Алерты | Письма LinkedIn Job Alerts и похожие разбираются в вакансии (`parse_linkedin.sh`) |
| 0c · Кнопки | Обрабатываются нажатия ✍️ 💶 ✅ из `data/ondemand.jsonl` по правилам `ONDEMAND.md` |
| 1 · Сбор | `./fetch_jobs.sh`: все ATS из `companies.tsv`, доски вакансий, staff.am |
| 2 · Веб | `./tg_channels.sh` и страницы из `./web_today.sh`: агрегаторы каждый день, сайты компаний по кругу третями |
| 3 · Запросы | Разовые задачи из `queue/requests.md`, после выполнения удаляются |
| 4 · Оценка | До 60 вакансий: оценка 1–10, подходит ли локация, «почему» одной строкой, какую версию CV брать |
| 5 · Топы | Продуктовый топ-10 и Solutions топ-5 из самых свежих с оценкой от 6. Остальное уходит в очереди по странам. Писем не больше 30 в день |
| 5b · Зарплаты | Вилка из вакансии или оценка с пояснением и цифрой для анкеты, не ниже порога из `config.json` |
| 6 · Трекер | Запись в коллекцию `jobs` |
| 7 · Статистика | Отклики, ответы и фоллоу-апы: через 7 дней или по дате `followup_on` |
| 8 · Дайджест | Сообщение в Telegram, затем карточки: CV, письмо, кнопки ✍️ 💶 ✅. В конце кнопки стран |
| 8b · Консалтинг | До 3 лидов на контракт или интерим с черновиком первого сообщения |
| 8c · LinkedIn | По понедельникам 10 людей, кому написать, с черновиками сообщений |
| 9 · Учёт | ID в `seen_ids.txt`, строка в `runs.log` |

## Ключевые правила (полностью в DAILY.md)

- **Факты только из CV-файлов.** Нельзя придумывать инструменты, цифры, объёмы.
- **Для конкурентов SkyRo** (Salmon и других кредиторов Юго-Восточной Азии) SkyRo показывается как «Lending fintech, Southeast Asia (NDA)», CV `tailored/cv_salmon_nda.html`. Ссылку на портфолио не ставить.
- **inDrive только наблюдаем:** никогда не в топе, одна строка «inDrive: N new» в конце.
- **Страну ремитанс-проекта не называть** (NDA). Пишем «Southeast Asia».
- **Стиль писем:** начинать с зацепки, человеческий тон, без ИИ-клише, 120–200 слов, одна честная строка про пробел. Для SA и технических PM добавлять ссылку на подходящий кейс портфолио.
- **Локации:** Мексика, США, Канада только удалённо. Сербия, Армения, Грузия, ОАЭ, ЕС подходят.

## Если прогон упал

Так было 30–31.10: в 9:05 не было интернета, ошибка `ENOTFOUND`.

1. Проверить в приложении Claude: Scheduled → `job-scout-daily` → Runs.
2. Перезапустить кнопкой **Run now** или попросить Claude «догони дайджест»: он соберёт вакансии и пришлёт пропущенное.
3. В `data/runs.log` у упавшего дня не будет строки. Это нормально: в `seen_ids.txt` ничего не записалось, и при следующем прогоне вакансии придут как новые.
