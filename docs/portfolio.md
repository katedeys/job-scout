# Портфолио

- **Публичная страница:** https://katedeys.github.io/katedeys-portfolio/ (репозиторий `katedeys/katedeys-portfolio`, GitHub Pages из ветки `main`).
- **Черновик для правок:** Claude-артефакт, ссылка в `scout/config.json → portfolio_draft_artifact`.
- **Исходник:** `portfolio/index.html` (формат артефакта, без `<html>/<head>`).
- **Файл для GitHub:** `portfolio/site/index.html` (полный HTML-документ, собирается из исходника).
- **Заметки к кейсам:** `portfolio/notes_orchestration.md` и др.

## Кейсы

| Якорь | Кейс |
|---|---|
| `#remittances` | Ремитансы Gulf → Southeast Asia: MVP, пивот в трансграничное погашение, скоринг. Архитектура и sequence |
| `#viban` | Virtual IBAN в оригинации: 100% автосверка. Архитектура, sequence выпуска и погашения, краевые случаи |
| `#payouts` | Выплаты кредитов (основной и запасной партнёр, ретраи лесенкой, FPX) и погашения (карты, VIBAN, наличные по QR), все события в Kafka |
| `#antifraud` | Платежи как источник данных для антифрода: точки проверки (списание, выдача кредита, выплата) и сигналы. Роль честно: владелец данных и консультант по правилам, не владелец фрод-продукта |
| `#orchestration` | Своя оркестрация в 40+ странах: таблица «проблема → решение», архитектура, состояния провайдера и пороги, sequence пополнения баланса водителем, переезд |

## Правила

- **Только по ссылке:** сайт закрыт от поисковиков (`noindex`). Ссылку даём только в CV, письмах и личных сообщениях. Не публикуем в постах, комментариях и профиле LinkedIn.
- **Всё обезличено:** без названий партнёров, внутренних сервисов и цифр сверх CV. Страна ремитанс-проекта в кейсе не называется. Исключение — раздел «The market» с открытыми данными по коридору UAE/KSA → Philippines; решение про NDA за Катей.
- **Пороги здоровья провайдера** подписаны как иллюстративные (лучшие практики индустрии).
- **«What I'd do differently»** должна написать Катя сама.

## Как обновить сайт

1. Попросить Claude поправить портфолио. Он меняет `portfolio/index.html`, публикует черновик и запускает `portfolio/build_site.sh --push "сообщение"`: скрипт собирает `site/index.html` и отправляет его в репозиторий сайта.
2. Загрузить файл на GitHub. После настройки git это делает Claude ([git.md](git.md)), иначе вручную: репозиторий → **Add file → Upload files** → `index.html` → **Commit changes**.
3. Через 1–2 минуты сайт обновится. Релиз не нужен. Если видишь старую версию, обнови страницу с очисткой кэша (Cmd+Shift+R).
